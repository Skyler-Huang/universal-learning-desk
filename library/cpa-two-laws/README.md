# cpa-two-laws

2026 年注册会计师《税法》+《经济法》两法知识包。它不是原始 PDF 的替代品，而是把已经跑过 OCR / 语义重切分的 1515 张卡片固化下来，方便直接重建知识台。

> ⚠️ **这个包里没有 `app_data.json`。** 出于教材授权原因，数据不随本仓库分发（见文末）。本文件只保留这个包的元数据与统计，说明「跑通之后长什么样」。要用它构建，请先用自有教材跑一遍流水线，产出 `app_data.json` 放到本目录。

## 统计

- 科目：税法 14 章 / 经济法 12 章，共 26 章
- 卡片：1515 张（税法 704 页、经济法 609 页的教材页序）
- 术语：168 条，全部从最终卡片正文派生
- 数字：6573 个数字 token，构建门禁要求零丢失、零新增
- 页面：单文件、离线、无 CDN

## 构建

在仓库根目录（前提：本目录下已有 `app_data.json`）：

```bash
python scripts/build_kb.py \
  --data library/cpa-two-laws/app_data.json \
  --out  output/cpa-two-laws.html \
  --title "CPA知识台"
```

打开 `output/cpa-two-laws.html` 即可。线上示例：<https://hletian.cn/cpa/>

## 来源与已知残余

- 来源：用户合法持有的 2026 年 CPA 教材；本地 RapidOCR 识别、语义切分、术语派生。
- `page` 是资料内部页序，不是出版社页码；`offsetBySubject` 记录了税法 8 / 经济法 9 的换算偏移。
- 12 张卡片以英文句点结尾（OCR 原样）；2 张超过 1000 字（整段法条/例题，为不截断而保留）。
- `lawRefs` / `lawVerified` 为空：没有引入外部法条库，也没有用推理补写。
- **仅限个人学习**。教材内容的再分发权利不在本仓库的代码许可范围内。
